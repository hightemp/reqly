# Reqly — TASKS

> Декомпозиция [PRD.md](PRD.md) на этапы → эпики → задачи. Оценок времени нет.
> Формат задачи: `- [ ] **ID** Название`, затем **Тесты** (пишутся первыми, TDD) и **Приёмка** (критерии готовности).
> Общий DoD для любой задачи описан в PRD §10: тесты до кода, линтеры, i18n en и ru, desktop + web, все темы, клавиатура.
