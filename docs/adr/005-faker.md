# ADR-005: Faker и локали данных

- Статус: принято
- Дата: 2026-10-17

## Контекст

Нужен генератор тестовых данных с синтаксисом `{{ $faker.person.firstName }}`
(имена категорий как в faker-js) и локалями en и ru (PRD §7.11). Генерация
должна выполняться в Rust, чтобы desktop и server давали одинаковый результат.

## Варианты

1. Crate `fake` 5.1: богатые наборы данных, 14 локалей.
2. Собственная реализация со встроенными наборами данных.

## Спайк

В `fake` 5.1 есть локали ar_sa, cy_gb, de_de, en, fa_ir, fr_fr, it_it, ja_jp,
nl_nl, pt_br, pt_pt, tr_tr, zh_cn, zh_tw. Русской нет, и её пришлось бы
дописывать вне crate, смешивая два способа генерации.

## Решение

Собственный модуль `reqly-template::faker`:

- реестр функций в нейминге faker-js (`person`, `internet`, `location`, `phone`,
  `company`, `lorem`, `number`, `string`, `datatype`, `date`, `color`,
  `commerce`, `finance`, `image`);
- наборы данных en и ru; для ru — род у фамилий (Иванов → Иванова), отчества,
  телефоны `+7`, шестизначные индексы, IBAN `RU…`, транслитерация
  для e-mail;
- алиасы динамических переменных Postman (`$guid`, `$randomFirstName`, …)
  сводятся к тем же функциям.

## Последствия

- Наборы данных меньше, чем в `fake`, но расширяются без внешних зависимостей.
- Новая локаль = новый модуль данных и ветки `Locale` в генераторах.
