# Импорт, экспорт и генерация кода

## Импорт

**Workspace → Импорт…** (или **Коллекция → Импортировать в эту коллекцию…**,
или командная палитра). Источник: файлы, папка, перетаскивание, вставленный
текст или URL. Формат определяется автоматически, его можно выбрать вручную.
Перед импортом мастер показывает дерево, число запросов, папок и окружений
и **отчёт** о том, что импортируется неточно. Отчёт можно скопировать или
сохранить. При импорте ничего не теряется молча.

| Формат | Что импортируется |
| --- | --- |
| Reqly (JSON / YAML) | всё: коллекции, окружения, секреты (если были экспортированы), cookies, история |
| Insomnia v3/v4 (JSON / YAML), v5 (YAML) | workspaces, папки (заголовки, auth, переменные, скрипты), запросы, все типы тела, path-параметры, настройки, окружения и подокружения, глобальные окружения, cookie jar, template tags |
| Postman Collection v2.0 / v2.1 | папки, запросы, тела всех режимов, auth, переменные коллекции (тип `secret`), path-переменные, `protocolProfileBehavior`, описания, скрипты |
| Postman Environment, Globals | окружения; можно выбрать вместе с файлом коллекции |
| OpenAPI 3.0 / 3.1, Swagger 2.0 (JSON / YAML) | теги → папки, `servers` и переменные сервера → переменные окружения (`base_url`), параметры с примерами, тела из примеров или схем, security schemes → auth с переменными |
| HAR 1.2 | запросы (лог, отдельная запись или запрос) |
| cURL | одна или несколько команд; строки, не являющиеся curl, попадают в отчёт |
| Bruno | папка коллекции или zip (`bruno.json`, `collection.bru`, `folder.bru`, `environments/`), отдельные `.bru` |

### Куда импортировать

- **Новая коллекция** — по одной коллекции на импортируемую.
- **В существующую коллекцию**:
  - *Объединить* — папки и запросы с тем же именем обновляются, остальное
    добавляется;
  - *Добавить рядом* — всё добавляется, существующее не трогается;
  - *Заменить* — существующие элементы сначала уходят в корзину (их можно
    восстановить).

Окружения коллекции становятся её окружениями, переменные — базовым
окружением. Отдельные окружения (файл Postman Environment, глобальные
окружения Insomnia или Reqly) при импорте в новую коллекцию становятся
глобальными окружениями workspace, при импорте в существующую коллекцию —
её окружениями.

Ссылки между запросами (`{% response 'body', '<id>', … %}`) переписываются
на новые запросы.

### Что попадает в отчёт

| Ситуация | Что делает Reqly |
| --- | --- |
| Скрипты (pre-request, tests, after-response) | сохраняются в запросе, но не выполняются до этапа 6 |
| Auth, которой пока нет (Digest, OAuth 1/2, AWS, NTLM, Hawk…) | запрос импортируется без auth, исходные параметры — в отчёте |
| WebSocket, gRPC, Socket.IO, MCP | пропускаются, данные — в отчёте |
| GraphQL-тело | импортируется как JSON `{ "query", "variables" }` |
| Auth и заголовки уровня коллекции (Postman, Bruno) | переносятся на элементы верхнего уровня |
| Скрипты уровня коллекции | в отчёте |
| Неизвестные template tags (плагины Insomnia) | остаются в тексте, отмечены в отчёте |
| Переменные Postman с точками и пробелами (`{{api.host}}`) | превращаются в `{{ _['api.host'] }}` |
| Сохранённые примеры ответов Postman, ответы в HAR | не импортируются (отмечено в отчёте) |
| Секреты Bruno | ключи создаются пустыми — значения хранятся вне коллекции |

## Экспорт

**Workspace → Экспортировать workspace…**, **Коллекция → Экспортировать
коллекцию…** или **Экспортировать…** в контекстном меню выбранных папок и
запросов.

| Формат | Что сохраняется |
| --- | --- |
| Reqly (JSON / YAML) | всё; опционально — значения секретов (с предупреждением), cookies, история ответов |
| Insomnia v4 (JSON) | коллекции, окружения, cookies; Reqly-синтаксис `{{ $fn() }}` переводится в теги |
| Insomnia v5 (YAML) | одна коллекция на файл |
| Postman v2.1 | коллекция + отдельный файл на каждое окружение |
| HAR 1.2 | запросы с применёнными заголовками папок (без ответов) |
| cURL | команды для всех запросов |

По умолчанию значения секретов в экспорт не попадают: ключи остаются, значения
пустые. В форматах Insomnia и Postman нет переменных уровня запроса и сетевых
настроек папок — при экспорте они теряются.

Спецификация собственного формата: [`docs/format/reqly.schema.json`](format/reqly.schema.json)
(`formatVersion` — semver; файлы старых версий обновляются при импорте, файлы
более новой версии не импортируются).

## Генерация кода

Кнопка `{ }` рядом с **Send**, пункт **Копировать как → …** в контекстном меню
запроса или команда палитры. По умолчанию переменные подставляются; можно
оставить шаблоны как есть. Выбранный язык запоминается.

| Группа | Таргеты |
| --- | --- |
| Shell | cURL (bash, cmd, PowerShell), Wget, HTTPie, PowerShell `Invoke-RestMethod` |
| JavaScript | fetch, Axios, XMLHttpRequest, Node.js `http`, undici |
| Python | Requests, HTTPX, `http.client` |
| Go, Rust | `net/http`, reqwest |
| Java, Kotlin | OkHttp, `HttpClient`; Kotlin OkHttp |
| C# | `HttpClient`, RestSharp |
| PHP, Ruby | cURL, Guzzle; `Net::HTTP` |
| Swift, Dart | `URLSession`, `http` |
