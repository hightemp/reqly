# Авторизация

У каждого запроса и папки есть вкладка **Авторизация**. Запрос использует
авторизацию ближайшей папки, где она задана, если не задал свою (или **Без
авторизации**). Во всех полях работают [переменные](help:variables).

| Схема                                      | Замечания                                                      |
| ------------------------------------------ | -------------------------------------------------------------- |
| Basic, Bearer, API key                     | заголовок или параметр запроса                                 |
| Digest                                     | отвечает на запрос сервера (MD5, SHA-256, `-sess`, `auth-int`) |
| NTLM                                       | NTLMv2; пользователя можно указать как `DOMAIN\user`           |
| OAuth 1.0                                  | подписи HMAC, RSA или PLAINTEXT                                |
| OAuth 2.0                                  | см. ниже                                                       |
| AWS Signature v4                           | с сессионными токенами и хешем тела для S3                     |
| Hawk, Atlassian ASAP, JWT, Akamai EdgeGrid | подпись для каждого запроса                                    |
| Netrc                                      | учётные данные из `~/.netrc` (только desktop)                  |

Подпись добавляется перед самой отправкой, поэтому **Копировать как cURL** и
сгенерированный код показывают запрос без подписи.

## OAuth 2.0

Способы получения: authorization code (с PKCE), client credentials,
password, device code и implicit.

- Токены client credentials и password получаются автоматически при
  отправке.
- Для authorization code, implicit и device code нужен вход: нажмите
  **Войти** на вкладке авторизации. На desktop страница провайдера
  открывается в окне Reqly, в браузере — во всплывающем окне.
- Токены хранятся зашифрованными и обновляются сами, если провайдер выдал
  refresh token. Запросы, наследующие авторизацию, используют токен папки.
  **Удалить токен** забывает его.
