# Совместная работа

Reqly может работать как сервер в браузере для команды. Каждый входит под
своей учётной записью; администраторы управляют пользователями в
**Настройки → Администрирование**.

## Общий доступ к пространству

**Действия с пространством → Участники…** приглашает людей по ссылке и
задаёт им роль:

| Роль        | Может                                                                                    |
| ----------- | ---------------------------------------------------------------------------------------- |
| Наблюдатель | открывать и отправлять запросы, запускать скрипты, экспортировать, переключать окружения |
| Редактор    | ещё и менять запросы, папки, коллекции, окружения, импортировать                         |
| Владелец    | ещё и переименовать или удалить пространство и управлять участниками                     |

Наблюдатель может пробовать изменения и отправлять запросы, но его
изменения не сохраняются.

## Одновременная правка

- Изменения других появляются сразу, без перезагрузки.
- Если двое правят один запрос, изменения разных полей сохраняются оба;
  для одного поля побеждает последнее сохранение, а второму человеку
  сообщается, кто его изменил.
- Тела, GraphQL-запросы и скрипты редактируются вместе в реальном времени,
  с курсорами и именами других.
- Аватары показывают, кто в пространстве и у кого открыт запрос.

## История ответов

Каждый видит свои ответы. Владелец может включить **Общая история ответов**
в **Участники…**, чтобы все видели все ответы.

## API-токены

**Настройки → Учётная запись** создаёт личные API-токены для скриптов, CLI
и [синхронизации desktop](help:sync).
