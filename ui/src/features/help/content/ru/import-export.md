# Импорт и экспорт

## Импорт

**Действия с пространством → Импорт…**, **Импортировать в эту коллекцию…** в меню
коллекции, **Импорт в эту папку…** на папке или палитра команд. Мастер
принимает файлы, папку, перетаскивание, вставленный текст или URL; формат
определяется автоматически. **Поддерживаемые форматы** в мастере
перечисляют их с примерами.

Перед импортом видны дерево, число запросов и окружений и **отчёт** обо
всём, что не удалось перенести точно. Выберите, куда импортировать: в новую
коллекцию или в существующую коллекцию или папку — _объединить_
(одноимённое обновляется), _добавить_ или _заменить_ (старое уходит в
корзину).

| Формат                        |                                                  |
| ----------------------------- | ------------------------------------------------ |
| Reqly (JSON / YAML)           | всё, включая окружения и историю                 |
| Insomnia v3–v5                | пространства, папки, запросы, окружения, cookies |
| Postman v2.0 / v2.1           | коллекции, окружения, globals, скрипты           |
| OpenAPI 3.x, Swagger 2.0      | теги → папки, servers → `base_url`               |
| HAR 1.2                       | записанные запросы из DevTools браузера          |
| cURL                          | одна или несколько команд                        |
| `.http` / `.rest`, сырой HTTP | JetBrains HTTP Client, VS Code REST Client       |
| Bruno                         | папка коллекции или zip                          |

## Запросы из буфера обмена

- Вставьте команду `curl` или HTTP-запрос в строку адреса, чтобы заменить
  текущий запрос.
- **Импорт из буфера обмена** в контекстном меню папки или запроса
  добавляет в эту папку все команды curl или HTTP-запросы из буфера.
- **Импорт запросов из cURL или HTTP-текста…** (палитра команд) открывает
  мастер на вкладке вставки.

HTTP-запрос выглядит так; несколько запросов разделяются `###`:

```
### Создать элемент
POST https://api.example.com/items
Content-Type: application/json

{"name": "Ada"}
```

## Экспорт

**Экспортировать workspace…**, **Экспортировать коллекцию…** или
**Экспортировать…** в
контекстном меню выделенных элементов. Форматы: Reqly (JSON или YAML),
Insomnia v4 и v5, Postman v2.1, HAR и cURL. Секретные значения остаются
пустыми, если вы их не включили.

К имени файла добавляются дата и время, например
`my-api-2026-11-27_14-05.reqly.json`, чтобы экспорты не перезаписывали друг
друга. Отключается в окне экспорта или в **Настройки → Общие**.
