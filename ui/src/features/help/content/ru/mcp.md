# MCP для агентов

В Reqly встроен [MCP](https://modelcontextprotocol.io)-сервер. AI-агенты —
Claude Code, Cursor, VS Code и другие — работают с запросами так же, как
вы: смотрят коллекции, меняют запросы, отправляют их, запускают коллекции,
читают ответы и управляют окружениями.

MCP **по умолчанию выключен**, а агентам доступны только разрешённые
инструменты.

## Включение

**Настройки → MCP → MCP-сервер**. Изменения применяются сразу, без
перезапуска.

- **Desktop**: приложение слушает `http://127.0.0.1:7655/mcp` — только на
  этом компьютере. Если порт занят, укажите другой в поле **Порт**; ошибка
  показывается красным. Сервер останавливается вместе с приложением.
- **Сервер**: адрес — `/mcp` на адресе сервера. На многопользовательском
  сервере MCP включает только администратор.
- В приложении для Android MCP-сервера нет.

Пока MCP включён, в строке состояния видна надпись **MCP**; щелчок по ней
открывает настройки.

## Токен

Каждый запрос агента содержит заголовок `Authorization: Bearer <токен>`.

- **Desktop и однопользовательский сервер**: токен создаётся при первом
  включении MCP и показывается **один раз** — скопируйте его сразу.
  **Новый токен** заменяет его; агенты со старым теряют доступ.
- **Многопользовательский сервер**: агенты используют личный API-токен
  (**Настройки → Учётная запись → API-токены**) и действуют с правами
  этого пользователя: видят только его workspaces, а агент наблюдателя
  ничего не может изменить.

## Подключение клиента

В блоке **Подключение клиента** — готовые настройки с вашим адресом и
токеном:

```text
claude mcp add --transport http reqly http://127.0.0.1:7655/mcp --header "Authorization: Bearer <токен>"
```

Cursor (`~/.cursor/mcp.json`) и VS Code (`.vscode/mcp.json`) принимают тот
же адрес и заголовок в виде JSON.

Codex (`~/.codex/config.toml`) берёт токен из переменной окружения:

```toml
[mcp_servers.reqly]
url = "http://127.0.0.1:7655/mcp"
bearer_token_env_var = "REQLY_MCP_TOKEN"
```

или `codex mcp add reqly --url http://127.0.0.1:7655/mcp --bearer-token-env-var REQLY_MCP_TOKEN`.
Запускайте Codex с `REQLY_MCP_TOKEN=<токен>` в окружении.

Чтобы указать агенту на запрос, выберите **Копировать путь / ID →
Копировать для ИИ** в контекстном меню запроса (в дереве или на вкладке):
копируются путь, ID, метод и URL и вызов `get_request`, который его читает.

## Инструменты

Инструменты разбиты на группы: отметьте группу целиком или раскройте её и
выберите отдельные инструменты. **Только чтение** и **Всё** выставляют все
сразу. При первом включении разрешены **Чтение** и **Отправка и запуск**.

| Группа             | Что может агент                                                                      |
| ------------------ | ------------------------------------------------------------------------------------ |
| Чтение             | список workspaces и коллекций, дерево, запросы, поиск, история, документация Reqly   |
| Изменение запросов | создать запрос или папку, изменить, переименовать, переместить, дублировать, удалить |
| Отправка и запуск  | отправить запрос, посмотреть его с подставленными значениями, запустить коллекцию    |
| Окружения          | читать и задавать переменные, создавать окружения, выбирать активное                 |
| Импорт и экспорт   | импорт cURL, `.http`, OpenAPI и другого текста, экспорт коллекции                    |

При подключении агент получает краткое описание Reqly, а инструмент
`get_docs` отдаёт любую страницу этой справки (на английском), так что
искать код Reqly агенту не нужно.

- Изменения сразу видны в открытых окнах, как правки коллеги; открытые
  редакторы их подхватывают.
- Удалённое попадает в **корзину**, его можно восстановить.
- Отправленные запросы сохраняются в **истории**, как ваши.
- Агент может отправить запрос с другим окружением или дополнительными
  переменными, не меняя ваше активное окружение.

## Секреты

Агенты не видят секретных значений: секретные переменные, пароли и токены
авторизации и заголовков показываются им как `••••` — в том числе внутри
ответов (если сервер возвращает заголовок обратно) и в запросе с
подставленными значениями. Значения вида `{{переменная}}` видны как есть.
Записывать секреты агент может; присланное обратно `••••` сохраняет
прежнее значение.

## Вызовы агентов

В списке **Вызовы агентов** — последние 200 вызовов: время, инструмент,
аргументы (без секретов), результат и длительность. Список хранится до
перезапуска приложения.
