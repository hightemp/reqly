# Запросы

## Адрес и параметры

Строка адреса и вкладка **Параметры** синхронизированы: параметры запроса из
адреса появляются в таблице и обратно. Параметры пути пишутся как `:name`
(`/users/:id`), их значения задаются в таблице. Во всех полях работают
[переменные](help:variables): `{{ base_url }}/users`.

## Заголовки

Заголовки запроса добавляются к заголовкам его папок. Строку можно
выключить, не удаляя. `Content-Type` тела выставляется автоматически, если
вы не задали свой.

## Тело

| Тип                         | Для чего                                             |
| --------------------------- | ---------------------------------------------------- |
| JSON, XML, YAML, Text, HTML | текст с подсветкой; `Ctrl+Shift+B` форматирует       |
| Form URL-encoded            | пары ключ — значение                                 |
| Multipart                   | поля и файлы                                         |
| Binary                      | файл как есть                                        |
| GraphQL                     | запрос и переменные, см. [Протоколы](help:protocols) |

## Авторизация

Вкладка **Авторизация**: Basic, Bearer, API key, Digest, NTLM, OAuth 1.0 и
2.0, AWS Signature v4 и другие. Запросы наследуют авторизацию папки. См.
[Авторизация](help:auth).

## Настройки

Вкладка **Настройки** запроса (и папки) переопределяет сетевые настройки:
таймауты, редиректы, проверку TLS, версию HTTP, прокси, сжатие,
подмену DNS. Общие значения — в **Настройки → Запросы и прокси**.

## Ответ

- **Тело**: форматированное (JSON, XML, HTML), как есть или предпросмотр
  (HTML, изображения, PDF, аудио и видео). JSON фильтруется через JSONPath
  (`$.items[0]`) или jq, XML — через XPath.
- **Заголовки**, **Cookies** и **Хронология**: обмен как есть, с временем DNS,
  соединения, TLS и первого байта.
- **Тесты** и **Консоль**: результаты [проверок](help:testing) и вывод
  скриптов.
- **История ответов** хранит прошлые ответы запроса; выберите ответ, чтобы
  посмотреть его снова.

**Журнал запросов** (палитра команд) показывает всё, что отправлялось
недавно. **Cookies** (палитра команд) — cookies пространства.

## Код и cURL

**Сгенерировать код…** превращает запрос в код на 26 языках и библиотеках
(cURL, fetch, Axios, Python Requests, Go, Java, C# и другие). **Копировать
как** в контекстном меню сразу копирует его. Вставка команды curl в строку
адреса делает обратное.

## Документация

Вкладка **Документация** у запроса или папки хранит описание в Markdown.
