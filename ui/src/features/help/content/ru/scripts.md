# Скрипты

Запросы, папки и коллекции могут выполнять JavaScript **перед** отправкой
запроса (pre-request) и **после** получения ответа (after-response).
Скрипты редактируются на вкладке **Скрипты** или в **Скрипты коллекции…** в
меню коллекции. Выполняются от коллекции к запросу.

## Примеры

```js
// Перед запросом: свежая метка времени и подпись
rq.variables.set('ts', Date.now());
rq.request.headers.upsert({ key: 'X-Sign', value: CryptoJS.SHA256('secret').toString() });

// После ответа: сохранить токен и проверить ответ
const body = rq.response.json();
rq.environment.set('token', body.token);
rq.test('статус 200', () => rq.response.to.have.status(200));
rq.test('есть элементы', () => rq.expect(body.items).to.not.be.empty);
```

## API

|                                                          |                                                                      |
| -------------------------------------------------------- | -------------------------------------------------------------------- |
| `rq.request`                                             | адрес, метод, заголовки и тело запроса                               |
| `rq.response`                                            | `code`, `headers`, `json()`, `text()`, `responseTime`                |
| `rq.variables`                                           | чтение любой переменной; `set` создаёт переменную времени выполнения |
| `rq.environment`, `rq.collectionVariables`, `rq.globals` | изменение окружений                                                  |
| `rq.test(name, fn)`, `rq.expect(value)`                  | тесты с проверками chai                                              |
| `rq.sendRequest(request)`                                | отправить другой запрос                                              |
| `rq.execution.skipRequest()`                             | не отправлять этот запрос                                            |
| `rq.faker`                                               | тестовые данные из faker-js                                          |
| `console.log(…)`                                         | вывод на вкладке **Консоль** ответа                                  |

`pm` (Postman) и `insomnia` — тот же API, поэтому импортированные скрипты
работают без изменений. `require()` даёт `crypto-js`, `lodash`, `chai`,
`moment`, `uuid` и `@faker-js/faker`. `await` работает на верхнем уровне.

## Переменные времени выполнения

`rq.variables.set` создаёт переменные, которые действуют в коллекции до
перезапуска приложения и переопределяют все остальные уровни. Их видно и
можно очистить в окне **Окружения** в разделе **Runtime (скрипты)**.

## Ограничения

У скриптов нет доступа к файлам и сети (кроме `sendRequest`). Скрипт,
который работает дольше 5 секунд или занимает больше 64 МБ,
останавливается. Ошибка pre-request скрипта отменяет запрос; ошибка видна
на вкладке **Консоль**.
