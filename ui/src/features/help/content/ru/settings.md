# Настройки

Откройте **Настройки** через `Ctrl+,` или шестерёнку в строке состояния.

| Раздел               |                                                            |
| -------------------- | ---------------------------------------------------------- |
| Общие                | язык, автосохранение, вид боковой панели, положение ответа |
| Внешний вид          | тема, плотность, шрифты, масштаб интерфейса, рамка окна    |
| Свои темы            | создание, правка, импорт и экспорт тем (JSON)              |
| Запросы и прокси     | таймауты, редиректы, TLS, версия HTTP, прокси              |
| Сертификаты          | сертификаты CA и клиентские сертификаты (PEM, PKCS#12)     |
| Шаблоны              | локаль тестовых данных                                     |
| История              | сколько и как долго хранить ответы                         |
| Сочетания клавиш     | изменение любого [сочетания](help:shortcuts)               |
| Синхронизация        | [синхронизация](help:sync) с сервером                      |
| MCP                  | [MCP-сервер](help:mcp) для AI-агентов                      |
| AI                   | [AI-чат](help:ai): провайдеры, модель, инструменты         |
| О программе и данные | версия, папка данных, очистка, обновления                  |

Строка состояния переключает тему, язык и положение ответа (справа или
снизу) одним щелчком.

## Обновления

Reqly проверяет новую версию при запуске и раз в день. **Проверить
обновления** (Настройки → О программе и данные, палитра команд) проверяет
сразу. Desktop-приложение скачивает обновление, проверяет подпись и
устанавливает его; **Перезапустить** завершает установку. Включите
**Устанавливать обновления автоматически**, чтобы это происходило в фоне,
или выберите канал **Предварительные версии**, чтобы получать бета-версии.

## Данные

Desktop-приложение хранит всё в локальной базе; секретные значения
шифруются ключом, который лежит рядом с ней. При переезде на другой
компьютер копируйте оба файла или используйте [экспорт](help:import-export)
либо [синхронизацию](help:sync).
