# Синхронизация

Desktop- и Android-приложение могут синхронизировать пространства с
сервером Reqly. Работайте офлайн как обычно: изменения уходят на сервер,
когда он доступен, и другие пользователи сервера их видят.

## Подключение

**Настройки → Синхронизация**: укажите адрес сервера, имя пользователя и
пароль (или API-токен). Пароль не сохраняется: Reqly хранит вместо него
личный API-токен, который можно отозвать в веб-интерфейсе.

## Выбор пространств

В списке — пространства этого устройства и сервера. Отметьте пространство,
чтобы синхронизировать его: пространство, которое есть только на
устройстве, выгружается (и на сервере принадлежит вам), а то, что есть
только на сервере, скачивается. Снятие отметки останавливает
синхронизацию; ничего не удаляется.

## Когда идёт синхронизация

При подключении, каждые 30 секунд, вскоре после изменения и по кнопке
**Синхронизировать** (настройки, палитра команд). Облако в строке состояния
показывает состояние: синхронизировано, есть неотправленные изменения, идёт
синхронизация, ошибка или конфликты.

## Что синхронизируется

Пространства, коллекции, папки, запросы и окружения. История, cookies,
токены OAuth 2.0 и настройки приложения остаются на каждом устройстве.
Секретные значения остаются на устройстве, пока не включена
**Синхронизировать секреты**.

## Конфликты

Изменения сливаются по полям, а текстовые поля — по отдельным правкам. Если
что-то удалили с одной стороны и изменили с другой, облако показывает
конфликт: откройте его и выберите, какую версию оставить.
