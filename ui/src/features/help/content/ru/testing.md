# Тесты и запуск коллекций

## Проверки

Вкладка **Тесты** запроса проверяет ответ без кода. В каждой строке
выбираются источник, оператор и ожидаемое значение:

| Источник     | Что проверяется      |
| ------------ | -------------------- |
| Статус       | код ответа           |
| Время ответа | миллисекунды         |
| Заголовок    | заголовок по имени   |
| Тело         | тело как текст       |
| JSONPath, jq | значение внутри JSON |

Операторы: равно, содержит, соответствует regex, меньше / больше,
существует и **соответствует JSON Schema**. В ожидаемых значениях работают
[переменные](help:variables). Результаты появляются на вкладке **Тесты**
ответа вместе с тестами скриптов (`rq.test`, см. [Скрипты](help:scripts)).

## Запуск коллекции

**Запустить коллекцию…** (меню коллекции, палитра команд) или **Запустить…**
на папке:

- выберите и упорядочьте запросы;
- выберите окружение для этого запуска;
- задайте число **итераций** и **файл данных** (CSV со строкой заголовков
  или JSON-массив) — значения каждой строки становятся переменными;
- добавьте паузу между запросами или остановку на первой ошибке.

Результаты появляются по мере выполнения. **Перезапустить упавшие** запускает
неудачные запросы снова. **Сохранить отчёт** пишет HTML, JUnit XML или JSON.

## В CI

`reqly-cli` запускает экспорт коллекции из командной строки и пишет те же
отчёты, поэтому тесты можно гонять в пайплайне.
