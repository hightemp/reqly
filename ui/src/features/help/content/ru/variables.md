# Переменные и окружения

## Как пользоваться переменными

Пишите `{{ name }}` в адресе, параметрах, заголовках, теле, полях
авторизации или в других переменных. Переменные подсвечиваются,
неопределённые — красным. Наведите курсор, чтобы увидеть значение; редактор
подсказывает имена при наборе, а сразу после `{{` — ещё и функции вроде
`$uuid` и `$timestamp`.

Работают и пути внутри JSON-значений: `{{ api.version }}`, `{{ hosts[0] }}`.

## Откуда берутся значения

Следующие уровни переопределяют предыдущие:

1. активное **глобальное окружение** пространства;
2. **базовое окружение** коллекции;
3. активное **окружение** коллекции (dev, stage, prod…);
4. **переменные папок**, от внешней папки к внутренней;
5. **переменные запроса** (вкладка **Переменные**);
6. переменные, заданные [скриптами](help:scripts) во время работы.

Окружения редактируются в окне **Окружения** (`Ctrl+E`) таблицей или JSON.
Активное окружение переключается в шапке боковой панели.

## Секреты

Отметьте ключ как секретный замком в его строке. Значение скрывается и
хранится зашифрованным. При экспорте секретные значения остаются пустыми,
если вы не решили их включить.

## Теги шаблонов

Функции вычисляют значения при отправке:

| Тег                                            | Что даёт                           |
| ---------------------------------------------- | ---------------------------------- |
| `{{ $uuid }}`, `{% uuid 'v7' %}`               | UUID                               |
| `{% now 'iso-8601' %}`                         | текущее время                      |
| `{% random 'int', 1, 100 %}`                   | случайное число или строку         |
| `{% base64 'encode', 'normal', 'user:pass' %}` | Base64                             |
| `{% hash 'sha256', 'hex', body %}`             | хеш или HMAC                       |
| `{% jwt 'encode', '{"sub":"1"}', secret %}`    | подписанный JWT                    |
| `{% prompt 'OTP', 'Код из SMS' %}`             | спрашивает перед отправкой         |
| `{% response 'body', '<запрос>', '$.token' %}` | значение из ответа другого запроса |

Наведите курсор на тег и нажмите **Изменить…** (или `Ctrl`+щелчок), чтобы
поменять аргументы с живым предпросмотром. Чтобы добавить новый тег, щёлкните
правой кнопкой в поле или редакторе и выберите **Вставить шаблонный тег…**:
выберите функцию и заполните аргументы (списки, числа, запрос из дерева).

## Цепочки запросов

`{% response %}` берёт значение из последнего ответа другого запроса: тело
(JSONPath `$.token` или XPath), заголовок, статус или адрес. Тот запрос
можно отправить заранее: если ответа ещё нет, если он устарел или каждый
раз.

### Пример: токен из ответа запроса логина

1. Отправьте запрос логина один раз, чтобы у него был ответ с токеном,
   например `{"token": "eyJ…"}`.
2. Откройте запрос, которому нужен токен, **Авторизация → Bearer-токен**.
3. Щёлкните правой кнопкой по полю **Токен** и выберите **Вставить
   шаблонный тег…**.
4. **Функция**: Ответ. **Атрибут**: Тело. **Запрос**: начните вводить имя
   запроса логина и выберите его. **Фильтр**: `$.token`.
5. **Когда отправлять**: «Никогда» берёт последний ответ; «Устарел»
   отправляет запрос логина снова, если ответ старше **максимального
   возраста**.
6. В предпросмотре виден токен. **Применить** вставляет
   `{% response 'body', '<id запроса>', '$.token' %}`.

Знать ID запроса не нужно: редактор подставит его сам. Если пишете тег
вручную, ID копирует **Копировать путь / ID → Копировать ID** в
контекстном меню запроса. Фильтры, импортированные из Insomnia
(`b64::…::46b`), работают как есть и показываются в редакторе обычным
текстом.

## Тестовые данные

`{{ $faker.person.firstName }}`, `{{ $faker.internet.email }}`,
`{{ $faker.number.int({ min: 1, max: 100 }) }}` — любые функции faker-js на
любой локали. Локаль задаётся в **Настройки → Шаблоны**. Работают и
динамические переменные Postman (`{{ $guid }}`, `{{ $randomEmail }}`,
`{{ $timestamp }}`…).
